# Calculator App

A simple calculator built using HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations
- Clear (C) button
- Delete (DEL) button
- Responsive design
- Simple and clean UI

## Technologies

- HTML5
- CSS3
- JavaScript

## Run

1. Clone the repository
2. Open `index.html` in your browser
